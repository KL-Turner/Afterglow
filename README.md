# Afterglow

*Fluorescence-lifetime voltage imaging -- the time of your life.*

Afterglow is the Moore lab's viewer for fluorescence-lifetime (FLIM) voltage imaging recorded on a
Leica STELLARIS FALCON and exported from LAS X: lifetime and intensity images, the phasor plot with
cursors, ROIs and their traces over time, projections, and motion correction.

This repository holds the **installers and release notes** only.

## Install

1. Download the newest installer from [Releases](../../releases/latest).
2. Run it. The first install also downloads the free MATLAB Runtime (no MATLAB licence needed); this
   takes a while once. Windows may warn that the publisher is unknown: choose **More info > Run
   anyway**.
3. Start **Afterglow** from the Start menu (right-click it to pin it to the taskbar).

## Updates

Afterglow checks for a newer version when it opens and offers **Update & Restart**. What changed in
each version is in its release notes.
